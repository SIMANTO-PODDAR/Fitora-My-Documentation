# Fitora

## Repository

[GitHub Repository](https://github.com/Developer-Moy/Fitora.git)

## Project Overview

Fitora is a fitness planner platform designed to help fitness enthusiasts and individuals interested in health and fitness manage their fitness journey through personalized tools, AI-powered assistance, nutrition planning, and workout tracking.

## Features

* Dashboard
* Nutrition Calculator
* AI Chat
* Set Goal
* User Management
* BMI Calculator
* GYM Timer
* Exercise Tracker
* Premium Meal Chart
* Premium Membership
* Gym-related Ads
* AI Trainer

## Sector Usage

Fitness enthusiasts or individuals interested in health and fitness.
